의료기기는 <span style={{ color: '#2f6fe0' }}>사이버보안을 통과해야 허가</span>가 난다. MindsNAVI AI는 이걸 자체 시험성적서로 정리했고, 아래가 그 35개 항목의 요구사항과 구현이다. 해당 없는 항목은 "해당 없음"으로 적었다.

기준은 식약처 「의료기기의 사이버보안 허가·심사 가이드라인」(2024 개정, 안내서-0995-05)이다. 국제표준 <span style={{ color: '#2f6fe0' }}>KS X IEC 62443-4-2</span>에 맞춰 요구사항이 <span style={{ color: '#2f6fe0' }}>15개 → 35개</span>로 늘었고, 2025.1.24 시행 디지털의료제품법에 대응한다.

# 개요

6개 영역, 35개 항목. **32개 적용 · 3개 해당 없음**.

# 01. 식별·인증 · IA

| ID | 요구사항 | 판정 | 구현 |
| --- | --- | --- | --- |
| IA-01 | 인터페이스별 식별·인증 | 적용 | 설문·대시보드 ID/비밀번호 인증 |
| IA-02 | 계정 관리 | 적용 | 대시보드에서 관리자 계정 CRUD |
| IA-03 | 계정 유일 식별 | 적용 | Seq + UUID 자동 부여 |
| IA-04 | 인증정보 주기 변경·보호 | 적용 | 최초·90일마다 재설정, 저장·전송 암호화 |
| IA-05 | 비밀번호 강도 | 적용 | 영문+숫자+특수문자 8자 이상 |
| IA-06 | 피드백 미노출 | 적용 | 입력 마스킹, 실패 원인 미구분 |
| IA-07 | 실패 시 접근 제한 | 적용 | 5회 실패 → 30분 잠금 |
| IA-08 | 시스템 사용 고지 | 적용 | 로그인 시 안내 문구 표시 |

# 정리

의료기기 사이버보안을 <span style={{ color: '#2f6fe0' }}>자체 시험성적서로 대체</span>한다는 건, 35개 항목을 서류로 증빙하는 일에 그치지 않는다. 인증·권한 모델, 암호화 대상과 키 관리, 감사로그 스키마, 보건의료정보 비식별화, 장애 복구까지 — <span style={{ color: '#2f6fe0' }}>시스템 설계와 DB 설계 단계부터</span> 이 요구사항을 전제로 프로그램이 설계되어야 한다.

즉 사이버보안은 개발을 끝낸 뒤 덧붙이는 기능이 아니라 <span style={{ color: '#2f6fe0' }}>설계 시점의 제약</span>이다. 처음부터 아키텍처에 녹여야 시험성적서가 실제 시스템과 어긋나지 않고, Digital GMP·임상허가·인허가 심사도 보완 없이 통과한다.
