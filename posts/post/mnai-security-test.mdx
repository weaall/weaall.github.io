소프트웨어가 의료기기(SaMD)가 되는 순간, 보안은 "있으면 좋은 것"이 아니라 <span style={{ color: '#2f6fe0' }}>허가 요건</span>이 된다. MindsNAVI AI는 의료기기 사이버보안 기준(식약처)에 따라 시험성적서(MAI-CSIC-VC)를 작성했고, 그 뼈대는 <span style={{ color: '#2f6fe0' }}>KS X IEC 62443-4-2</span>의 6개 요구사항 패밀리다.

<br />

# 6개 요구사항 패밀리

보안 요구사항을 6개 계열(IA·UC·SI·DC·TRE·RA)로 나눠 설계·검증한다. 총 **36개 항목** 중 33개 적용, 3개는 SaMD 특성상 해당 없음.

# IA — 식별·인증

- 인터페이스별 사용자·관리자 인증, 계정 생성·활성·비활성·삭제 관리
- 고유 식별자 <span style={{ color: '#2f6fe0' }}>Seq + UUID</span>
- 자격증명 관리 — 최초 로그인 시 + <span style={{ color: '#2f6fe0' }}>90일마다</span> 비밀번호 재설정 강제
- 비밀번호 강도 — 영문·숫자·특수문자 <span style={{ color: '#2f6fe0' }}>8자 이상</span>
- <span style={{ color: '#2f6fe0' }}>5회 실패 → 30분 잠금</span>, 실패 메시지는 일반화(계정 존재 노출 방지)
- 시스템 사용 고지 배너(설정 가능)

# UC — 사용통제

- 최소권한 역할기반 접근 <span style={{ color: '#2f6fe0' }}>PBAC</span>
- 모바일 코드 통제 — <span style={{ color: '#2f6fe0' }}>CSP</span> 헤더
- 비활성 시 세션 잠금·자동 만료
- 감사로그 생성(시각·출처·분류·유형·이벤트ID·결과), 부인방지 <span style={{ color: '#2f6fe0' }}>userSeq</span>
- 감사 실패 대비 — Cloud DB(MySQL) 자동 failover

# SI — 시스템 무결성

- 전송 무결성 <span style={{ color: '#2f6fe0' }}>TLS 1.3</span>
- 악성코드 ClamAV / 실시간 위협 <span style={{ color: '#2f6fe0' }}>Falco(IDS)</span> · <span style={{ color: '#2f6fe0' }}>WAF(ModSecurity)</span>
- 무결성 — 컨테이너 이미지 <span style={{ color: '#2f6fe0' }}>SHA-256 다이제스트 검증</span> + GitOps(ArgoCD) 드리프트 복구 + Falco 런타임 변조 탐지
- 입력 검증(MIME 스니핑·클릭재킹·SQLi/XSS 방어), 정보 미노출 오류 처리
- 이미지 진본성 — NCR + IAM
- SI-06 · SI-10 · SI-11 은 **해당 없음** (SaMD · 무자동화 연계 · 무물리장치)

# DC — 데이터 기밀성

- 저장·전송 기밀성, TLS 1.3 (Wireshark로 검증)
- <span style={{ color: '#2f6fe0' }}>보건의료정보 비식별화</span> — 환자 신원 미도출
- 안전한 암호 — 비밀번호 <span style={{ color: '#2f6fe0' }}>SHA-256 + salt</span>, 그 외 데이터 <span style={{ color: '#2f6fe0' }}>AES-256</span>, 키 안전 보관

# TRE — 적시 대응

- 감사로그는 종합관리자만 <span style={{ color: '#2f6fe0' }}>읽기 전용</span>으로 접근, 수정 기능 없음

# RA — 자원 가용성

- DoS/DDoS 방어 <span style={{ color: '#2f6fe0' }}>NCP Anti-DDoS</span>
- 백업 — Cloud DB 자동 백업 + <span style={{ color: '#2f6fe0' }}>PITR</span> (민감 백업 암호화, 키 분리)
- 복구 — NKS self-healing + 선언적 재적용 + 다이제스트 고정 이미지 + Cloud DB HA
- 네트워크·보안 설정 — ACG 방화벽 + Cloud Activity Tracer, 불필요 포트 차단(HTTPS 443만)

**33 / 36 적용**. 나머지 3개(SI-06·10·11)는 SaMD 특성상 해당 없음 — 물리 변조·부팅 무결성·자동화 프로세스 연계가 없기 때문.

| 패밀리 | 핵심 통제 | 근거·구현 |
| --- | --- | --- |
| IA | 인증·계정·잠금 | UUID · 90일 재설정 · 5회 30분 잠금 |
| UC | 최소권한·감사 | PBAC · CSP · userSeq 부인방지 |

| DC | 기밀성·비식별 | AES-256 · SHA-256+salt · 비식별화 |
| TRE | 로그 보호 | 종합관리자 읽기 전용 |
| RA | 가용성·복구 | Anti-DDoS · PITR · NKS self-healing |

# 정리

시험성적서(MAI-CSIC-VC)는 제조사 자기적합성 문서로, KS X IEC 62443-4-2 기준을 SaMD에 매핑해 6개 패밀리 전 항목을 적용/해당없음으로 판정한다(품질책임자 검토·경영진 승인). 밑바탕에는 <span style={{ color: '#2f6fe0' }}>CSAP 인증 네이버 클라우드</span> 위의 인프라·GitOps·관측성이 근거로 깔린다.

보안이 곧 허가의 일부인 의료 소프트웨어에서, 이 매핑은 <span style={{ color: '#2f6fe0' }}>인허가 기술문서의 핵심 근거</span>가 된다.
