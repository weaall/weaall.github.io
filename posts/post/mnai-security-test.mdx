SaMD(소프트웨어 의료기기)에서 보안은 <span style={{ color: '#2f6fe0' }}>허가 요건</span>이다. MindsNAVI AI의 사이버보안 시험성적서를 <span style={{ color: '#2f6fe0' }}>KS X IEC 62443-4-2</span> 6개 패밀리·36개 항목으로 정리했다 — 각 항목의 요구사항과 해소 방안까지.

# 6개 패밀리

33개 적용, 3개는 SaMD 특성상 해당 없음.

# 전체 항목

## IA · 식별·인증

| ID | 요구사항 | 판정 | 해소 |
| --- | --- | --- | --- |
| IA-01 | 인터페이스별 식별·인증 | 적용 | 설문·대시보드 ID/비밀번호 인증 |
| IA-02 | 계정 관리 | 적용 | 대시보드에서 관리자 계정 CRUD |
| IA-03 | 계정 유일 식별 | 적용 | Seq + UUID 자동 부여 |
| IA-04 | 인증정보 주기 변경·보호 | 적용 | 최초·90일마다 재설정, 저장·전송 암호화 |
| IA-05 | 비밀번호 강도 | 적용 | 영문+숫자+특문 8자 이상 |
| IA-06 | 피드백 미노출 | 적용 | 입력 마스킹, 실패 원인 미구분 |
| IA-07 | 실패 시 접근 제한 | 적용 | 5회 실패 → 30분 잠금 |
| IA-08 | 시스템 사용 고지 | 적용 | 로그인 시 안내 문구 표시 |

## UC · 사용통제

| ID | 요구사항 | 판정 | 해소 |
| --- | --- | --- | --- |
| UC-01 | 최소권한 부여 | 적용 | 역할 기반 최소권한(PBAC) |
| UC-02 | 모바일 코드 통제 | 적용 | CSP 헤더로 실행 제어 |
| UC-03 | 세션 잠금 | 적용 | 미입력 시 자동 세션 만료 |
| UC-04 | 감사기록 생성 | 적용 | 감사로그(시각·출처·유형·결과) 실시간 |
| UC-05 | 감사 실패 대비 | 적용 | Cloud DB 자동 페일오버 |
| UC-06 | 타임스탬프 | 적용 | 감사로그에 타임스탬프 포함 |
| UC-07 | 부인 방지 | 적용 | userSeq 포함 행동 로그 |

## SI · 시스템 무결성

| ID | 요구사항 | 판정 | 해소 |
| --- | --- | --- | --- |
| SI-01 | 전송 무결성 | 적용 | HTTPS · TLS 1.3 |
| SI-02 | 악성코드 방지 | 적용 | 서버 ClamAV 상시 검사 |
| SI-03 | 보안 기능 검증 | 적용 | Falco(IDS) · WAF(ModSecurity) |
| SI-04 | 무결성 점검 | 적용 | 이미지 SHA-256 검증 · ArgoCD 복원 · Falco |
| SI-05 | 입력 검증 | 적용 | 클릭재킹·SQLi·XSS 방어 |
| SI-06 | fail-safe 출력 | 해당 없음 | 자동화 프로세스 미연결 |
| SI-07 | 정보 미노출 오류 처리 | 적용 | 예외별 메시지, 원인 미노출 |
| SI-08 | 업데이트 기능 | 적용 | NKS 무중단 패치 |
| SI-09 | 업데이트 진본성 | 적용 | NCR + IAM, SHA-256 digest |
| SI-10 | 물리 변조 방지 | 해당 없음 | 소프트웨어 의료기기 |
| SI-11 | 부트·런타임 무결성 | 해당 없음 | 소프트웨어 의료기기 |

# 적용 현황

**33 / 36 적용.** 나머지 3개(SI-06·10·11)는 물리·부팅 무결성·자동화 연계가 없는 SaMD라 해당 없음.

# 정리

제조사 자기적합성 시험성적서로, 각 항목을 <span style={{ color: '#2f6fe0' }}>CSAP 네이버 클라우드</span> 위 인프라·GitOps·관측성으로 해소했다. 보안이 곧 허가의 일부인 의료 소프트웨어에서, 이 항목별 매핑이 <span style={{ color: '#2f6fe0' }}>인허가 기술문서의 근거</span>가 된다.
