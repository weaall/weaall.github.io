<span style={{ color: '#2f6fe0' }}>치유포레스트</span>는 기관 PC에 설치되는 소프트웨어 의료기기(SaMD)다. 제조사가 직접 작성한 사이버보안 시험성적서로 <span style={{ color: '#2f6fe0' }}>의료기기 변경 허가</span>를 받았다. 아래가 35개 항목의 요구사항과 구현이다.

폐쇄망 범용 PC에 설치·운영되는 제품이라, 백신·DoS·네트워크 구성 같은 <span style={{ color: '#2f6fe0' }}>운영 환경(기관) 책임 항목은 해당 없음</span>으로 두고, 프로그램이 갖춰야 할 인증·무결성·암호화·백업·복구를 자체 구현했다.

# 개요

6개 영역, 35개 항목. **27개 적용 · 8개 해당 없음**.

# 01. 식별·인증 · IA

| ID | 요구사항 | 판정 | 구현 |
| --- | --- | --- | --- |
| IA-01 | 인터페이스별 식별·인증 | 적용 | 관리자·사용자 로그인, 실패 시 오류 메시지 |
| IA-02 | 계정 관리 | 적용 | 관리자 페이지에서 계정 수정·삭제 |
| IA-03 | 식별정보 관리 | 적용 | 고유 Seq 자동 생성 + ID 중복 확인 |
| IA-04 | 인증정보 관리·보호 | 적용 | 초기 변경 유도·90일 주기 변경, SHA-256+salt 저장 |
| IA-05 | 비밀번호 강도 | 적용 | 조합 규칙 강제 |
| IA-06 | 피드백 미노출 | 적용 | 입력 마스킹, 실패 원인 미구분 |
| IA-07 | 실패 시 로그인 제한 | 적용 | 5회 실패 → 5분 잠금 |
| IA-08 | 시스템 사용 고지 | 적용 | 관리자 등록 문구 로그인 시 표시 |

# 정리

치유포레스트는 폐쇄망에 설치되는 SaMD라, 클라우드형과 달리 <span style={{ color: '#2f6fe0' }}>운영 환경(백신·네트워크·물리)은 기관 책임</span>으로 두고 프로그램이 책임질 항목(인증·무결성·암호화·백업·복구)만 자체 구현했다.

핵심은 같다 — 사이버보안을 자체 시험성적서로 갈음하려면 <span style={{ color: '#2f6fe0' }}>제품을 그렇게 설계</span>해야 하고, 그 구현이 변경 허가의 근거가 된다.
