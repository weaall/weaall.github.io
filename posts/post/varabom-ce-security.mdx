VR 인지기능 훈련 프로그램 <span style={{ color: '#2f6fe0' }}>바라봄 CE(Varabom.CE)</span>는 제조사가 직접 작성한 사이버보안 시험성적서로 <span style={{ color: '#2f6fe0' }}>의료기기 임상시험 허가</span>를 받았다. 아래가 그 35개 항목의 요구사항과 구현이다. 해당 없는 항목은 "해당 없음"으로 적었다.

바라봄 CE는 기관 PC에 설치되는 소프트웨어 의료기기(SaMD)다. 클라우드가 아니라 <span style={{ color: '#2f6fe0' }}>로컬 설치형</span>이라 보안을 인프라가 대신 처리할 수 없고, 프로그램 자체가 인증·로깅·암호화를 갖춰야 했다.

# 개요

6개 영역, 35개 항목. **29개 적용 · 6개 해당 없음** — 폐쇄망 설치형이라 DoS·모바일 코드·물리/부팅 무결성 등은 해당 없음이다.

# 01. 식별·인증 · IA

| ID | 요구사항 | 판정 | 구현 |
| --- | --- | --- | --- |
| IA-01 | 인터페이스별 식별·인증 | 적용 | 사용자앱·관리자 ID/비밀번호 인증 |
| IA-02 | 계정 관리 | 적용 | 관리자에서 계정 추가·수정·삭제 |
| IA-03 | 식별정보 관리 | 적용 | 계정마다 고유 식별자(Seq/UUID) |

| IA-06 | 피드백 미노출 | 적용 | 입력 마스킹, 실패 원인 미구분 |

# 정리

바라봄 CE는 뒤에서 받쳐주는 클라우드가 없는 로컬 설치형 SaMD다. 그래서 인증·감사 로그(varabom_log)·암호화·업데이트 절차를 <span style={{ color: '#2f6fe0' }}>프로그램 설계와 DB 설계 단계부터</span> 넣어야 했고, 그 구현이 곧 시험성적서의 증거가 됐다.

사이버보안을 자체 시험성적서로 갈음한다는 건, 서류를 채우는 게 아니라 <span style={{ color: '#2f6fe0' }}>제품을 그렇게 설계했다는 증명</span>이다. 그 증명으로 임상시험 허가까지 이어졌다.
