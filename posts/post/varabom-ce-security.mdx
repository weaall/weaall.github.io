VR 인지기능 훈련 프로그램 <span style={{ color: '#2f6fe0' }}>바라봄 CE(Varabom.CE)</span>는 제조사가 <span style={{ color: '#2f6fe0' }}>직접 작성한 사이버보안 시험성적서</span>로 의료기기 임상시험 허가를 받았다. 외부 인증서 없이 자체 시험서로 사이버보안 요건을 갈음한 것이다.

바라봄 CE는 기관에 설치되는 소프트웨어 의료기기(SaMD)다. 클라우드 서비스가 아니라 로컬 설치형이라, 보안을 "인프라가 대신 처리"할 수 없고 <span style={{ color: '#2f6fe0' }}>프로그램 자체가 인증·로깅·암호화를 갖춰야</span> 했다.

# 어떻게 처리했나

## 로그인·계정 (IA)

초기 비밀번호를 최초 로그인 시 강제로 바꾸게 하고, 로그인을 <span style={{ color: '#2f6fe0' }}>5회 실패하면 계정을 잠근다.</span> 실패 메시지는 아이디·비밀번호를 구분하지 않아 계정 존재 여부가 새지 않는다.

![로그인 실패 시 계정 잠금 안내](/assets/posts/varabom/login-lockout.png)

![초기 비밀번호 강제 변경](/assets/posts/varabom/password-reset.png)

## 감사 로그 (UC·TRE)

접속·조회·생성·변경·삭제 활동을 로컬 DB의 <span style={{ color: '#2f6fe0' }}>감사 테이블(varabom_log)</span>에 남긴다. VR 콘텐츠 실행과 오류·이벤트도 로그 파일로 기록되며, 로그는 권한자만 조회할 수 있다.

## 무결성·악성코드 (SI)

악성코드 대응으로 ClamAV를 두고, 업데이트는 정해진 절차(서버·메인 프로그램 재설치 → 포트·기관번호 입력)로만 이뤄진다. SaMD라 <span style={{ color: '#2f6fe0' }}>물리 변조·부팅 무결성 항목은 해당 없음</span>이다.

## 암호화 (DC)

개인정보는 AES-256으로 저장하고, 비밀번호는 SHA-256+salt(단방향)로, 통신 구간은 TLS로 보호한다.

# 결과

바라봄 CE는 이 시험성적서로 <span style={{ color: '#2f6fe0' }}>의료기기 임상시험 허가</span>를 받았다. 별도의 외부 보안 인증 없이 제조사 자체 시험서가 그대로 인정된 사례다.

# 정리

로컬 설치형 SaMD는 뒤에서 받쳐주는 클라우드가 없다. 그래서 인증·감사 로그·암호화·업데이트 절차를 <span style={{ color: '#2f6fe0' }}>설계 단계부터 프로그램에 넣어야</span> 자체 시험서가 성립하고, 그게 곧 임상허가의 근거가 된다.
